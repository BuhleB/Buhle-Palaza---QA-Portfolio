My approach

Make each result explainable.

01 / SCOPE

Start with the risk

Identify the user journey, expected behaviour and what matters if it fails.

02 / TEST

Exercise the boundaries

Check successful flows, invalid input and behaviour across relevant browsers.

03 / INVESTIGATE

Explain the failure

Separate application defects from test issues, demo data and missing requirements.

04 / VERIFY

Keep the evidence

Record outcomes, retest changes and check related workflows for regression.
