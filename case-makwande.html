Invalid-email check

Run-Test `
    -TestID "TEST-04" -Section "Contact Form" -SRSRef "FR-18" `
    -Description "Invalid email format rejected" `
    -CurlArgs @("-s", "-X", "POST", "$BASE_URL/contact",
                "-F", "full_name=Buhle",
                "-F", "email=notanemail",
                "-F", "subject=Test",
                "-F", "message=Hello") `
    -ExpectedFragment "valid email"

Sends an invalid email to /contact. The runner passes this check when the response contains “valid email”. It does not check the stored database record.

Scope and limits
  • The 30-check report covers the PowerShell HTTP runner. The four pytest checks form a separate suite.
  • HTTP checks match response text or status codes; they do not verify database persistence. Free Pipeline is outside this runner’s coverage.
  • TEST-20 checks for “success” and TEST-21 for “400”; these checks do not verify XSS or CSRF protection.
